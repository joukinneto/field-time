# REPORT LANGUAGE POLICY

Project: JKDD Field - Field Time  
Developer: JKDD TECH  
Policy status: Official  
Date: 2026-08-02

## Official Rule

All official reports, PDFs, spreadsheets, CSV files and exports generated by JKDD Field - Field Time must be generated in English (US), regardless of the language selected in the app interface.

The app interface continues to support:

- Portuguese
- English
- Spanish

The report/export language does not follow the interface language.

## Documents Always Generated In English

- Timesheet PDF
- Weekly Timesheet
- Monthly Timesheet
- Yearly Timesheet
- Receipt Report
- Expense Report
- Reimbursement Report
- Employee Report
- Job Report
- Supervisor Report
- Audit Report
- All PDFs
- All Excel (XLSX) exports
- All CSV exports
